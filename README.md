# מחשבון התאמות

אפליקציית אינטרנט בקובץ יחיד (`index.html`) לחישוב התאמות מספריות.
היא פועלת כולה בדפדפן: בלי שרת, בלי התקנה ובלי חיבור לאינטרנט.

## הפעלה

- פתיחה מקומית: פתח את `index.html` בדפדפן.
- אתר ב-GitHub Pages: ב-Settings → Pages בחר Branch: `main` ותיקייה `/ (root)`. האתר יעלה בכתובת `https://<שם-משתמש>.github.io/<שם-המאגר>/`.

## פרטיות

ההגדרות נשמרות במכשיר בלבד (`localStorage`). האפליקציה לא שולחת נתונים לשום מקום.
